# ИИ-бот ВК «Играй и учись»

Бот принимает новые сообщения сообщества ВК через Callback API, передаёт текст в официальный Gemini API и отправляет сформированный ответ родителю от имени сообщества.

## Что умеет

- отвечает на свободные вопросы родителей с помощью ИИ;
- рассказывает о трёх учебных направлениях;
- помогает начать запись в группу;
- показывает кнопки выбора программы и перехода на сайт;
- не придумывает цену, расписание или адрес;
- скрывает телефоны и адреса электронной почты перед отправкой текста в ИИ;
- возвращает `ok` ВКонтакте сразу, а обработку выполняет в фоне.

## Переменные Vercel

Добавьте значения из `.env.example` в Settings → Environment Variables. Секретные значения нельзя сохранять в GitHub.

Обязательные переменные: `VK_TOKEN`, `VK_GROUP_ID`, `VK_CONFIRMATION_CODE`, `VK_SECRET`, `GEMINI_API_KEY`.

Модель по умолчанию: `gemini-3.1-flash-lite`. Бот отбрасывает служебные части ответа Gemini и отправляет родителю только финальный текст на русском языке.

После публикации Callback URL будет иметь вид:

`https://<имя-проекта>.vercel.app/api/vk`

## Подключение в VK

1. Управление сообществом → Работа с API → Callback API.
2. Вставьте Callback URL.
3. Укажите ту же секретную строку, что сохранена в `VK_SECRET`.
4. Подтвердите сервер.
5. В типах событий включите «Входящие сообщения».
